# ♠️ Poker Academy

An interactive, single-page web application designed to teach **Texas Hold'em Poker** to absolute beginners. Built with React and Tailwind CSS, this project uses visual learning, dynamic calculators, and state-based quizzes instead of walls of text.

---

## 🎯 What This Application Teaches

The academy is structured into 6 progressive, interactive modules:

1. **Terminology & Hand Rankings:** Learn key poker jargon and play an interactive hand-sorting game to master the 10 hand rankings (from Royal Flush down to High Card).
2. **Flow of Play & Action Mechanics:** A street-by-street simulator (Pre-flop, Flop, Turn, River, Showdown) demonstrating betting actions (*Check, Bet, Call, Raise, Fold*).
3. **Table Position & The Blinds:** A clickable 9-max virtual table mapping position tiers (*Blinds, Early, Middle, Late Position*) and position advantage.
4. **Pot Odds & Expected Value (EV):** A dynamic slider calculator for pot odds, required equity, the Rule of 2/4, and EV calculations (+EV vs -EV).
5. **Edge Cases & "Who Wins?" Quiz:** Interactive scenarios testing kicker tie-breakers, split pots, and flush evaluation.
6. **Beginner Strategy & Psychology:** A guide to Tight-Aggressive (TAG) strategy and an interactive pre-flop starting hand selection matrix.

* **Tailwind CSS** (Casino-themed dark green `#064e3b` felt backdrop with gold accents)
* **HTML5 & Modern JavaScript**

## 🚀 How to Open & Run

1. Clone or download the repository to your computer.
2. Open `index.html` (or `Poker_Academy.html`) in any web browser (Chrome, Firefox, Safari, or Edge).
3. No installation or build steps required!
